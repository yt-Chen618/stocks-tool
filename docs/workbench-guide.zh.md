# 工作台使用说明

先从“研究”页开始。这个工作台帮助你核对证据、比较方案和复盘；每个结果旁边会说明数据时间、缺口和下一步。

## 第一次使用

1. 看顶栏的账户和“模拟交易 / Paper”标识。这里应是你选中的账户；演示页面另有黄色“演示数据”提示。
2. 在“研究”里选择一个标的，切到“图表”。表格、走势图和右侧解释会跟着同一个标的变化。
3. 依次读“我看到了什么”“这意味着什么”“现在可以做什么”。均线只是在比较一段时间的平均价格，不能单独说明未来会涨或跌。
4. 打开策略评估，检查适用条件和阻塞原因。评估通过也不等于获得下单许可；交易时后端还会重新核对账户、持仓、报价和风险限额。
5. 展开“保存、加载与比较”，保存筛选方案，再保存一条研究记录，写下关注理由和下一步。筛选方案可以修改；已经保存的研究记录展示的是当时的数据快照。

正式页面的研究记录保存在数据库，换浏览器后可以重新读取。演示页面使用内存样例，重启演示服务会重置，不能用来保存正式研究。

## 盘前 / 收盘 / 盘后对照

在“市场”入口里，输入标的后点击“读取最新对照”。工作台会读取同一账户、同一模拟盘模式下的盘前基准，并按美东交易日核对常规收盘参考和盘后报价。盘前基准来自已保存的盘前运行记录，不能由浏览器填写价格代替。

如果要把这次读取保存下来，点击“采集并记录时段报价”。这只读取券商行情、市场日历和必要的日线参考，并在本地保存不可变记录；它不会提交订单，也不会修改账户。重复使用同一个采集键和完全相同的请求会返回原记录；同一个键改了标的、账户、模式或盘前记录会报冲突。没有采集键时，每次都是新的观察记录。

页面显示三块证据：盘前基准、常规收盘、盘后报价，并分别显示“盘前 → 收盘”和“收盘 → 盘后”。常规收盘只有在真实交易日的收盘边界之后才成立：普通日为美东 `16:00`，确认的半日市为 `13:00`。收盘字段是同日 Longbridge 收盘参考或经过验证的同日收盘日线，不等同于官方收盘竞价成交价。盘后行情缺失、陈旧、跨交易日、时间无时区或币种未确认时保持空白，不能当成 `0`。

“已保存的对照”可以按账户、模式和标的加载，历史记录使用游标分页。默认时间按中国时间显示，市场边界和证据时间同时标注美东时间。演示页面的数据保存在内存中；重启 mock/demo 服务或执行 demo reset 后，已保存的演示对照会清空，不能当作真实市场记录。

## 五个入口怎么用

| 入口 | 你主要看什么 | 看完可以做什么 |
| --- | --- | --- |
| 研究 | 标的价格、趋势、事件、证据是否完整 | 比较候选、保存研究记录、打开策略评估 |
| 策略 | 方案怎么运作、哪里可能亏损、历史任务与假设 | 检查条件、查看提案、创建或查看离线回测 |
| 市场 | 事件发生时间和关联标的 | 查看事件来源，回到对应标的研究 |
| 持仓 | 资产变化、钱放在哪里、到期与风险集中度 | 从汇总查看持仓、成交和复盘记录 |
| 运行与安全 | 数据是否更新、哪些条件未满足 | 查看中文原因、明细和恢复记录 |

## 这些数字分别是什么意思

- **净值变化**：两次账户资产总值之差，可能包括入金、出金和投资盈亏。缺少完整出入金记录时，页面不会把它称为投资收益率。
- **持仓权重**：该持仓市值占账户净值的比例。含杠杆时可能超过 100%，不能直接理解为现金分配比例。
- **最大回撤**：回测过程中，从此前最高资产值下降得最多的一段。它描述已模拟的路径，不是未来亏损上限。
- **已知最大损失**：只统计有足够数据、可以计算的策略部分。它不是整个账户的全部风险；股票下跌、未知报价或缺少 Greeks 等项目会另行列出。
- **费用与滑点**：费用是交易成本；滑点是模拟成交价相对参考报价的不利变化。回测必须写明假设，不能把未知费用当成零。

## 看到缺失或阻塞时

| 页面提示 | 含义 |
| --- | --- |
| 暂不可用 / 获取失败 | 当前没有拿到足够数据，不代表数值为零 |
| 陈旧 | 有旧数据，但时间不满足当前用途 |
| 历史模式或来源待确认 | 记录仍然保留，但不能作为模拟账户的开仓凭据 |
| 缺少数据 / BLOCKED_DATA | 回测所需数据、授权、范围或质量尚未满足 |
| 失败 / 中断 / 已取消 | 任务没有产生可以当作策略表现使用的成功结果 |
| 0 或 0% | 只有数据充分、后端明确计算出零时才这样显示 |

默认时间按中国时间展示。美股开收盘、到期和事件同时参考美东时间；夏令时切换会改变两地时差。

## 历史回测的边界

完整目标仍是 2020-01-01 至 2026-09-30，开发期为 2020—2023 年，验证期为 2024 年，2025 年起是参数冻结后的样本外检验。不要为了让结果好看，反复根据样本外表现改参数。

当前没有授权的多年历史期权数据，真实历史验证保持 `BLOCKED_DATA`。样例或合成数据仅证明程序的读取、计算和生命周期处理能够工作，不能证明策略有收益。查看回测时还应核对数据版本、引擎版本、代码版本、费用、滑点和生命周期假设。

小屏幕可以查阅，券商写操作继续禁用。真实模拟盘试单需要另行授权；实盘和零日期权执行保持锁定。
